# তানাখ — অসমীয়া অনুবাদ (selah-as)

এইখন হিব্ৰু ধৰ্মপুথিৰ (তানাখ) অসমীয়া অনুবাদ। প্ৰতিটো পদ নিজৰ
ফাইলত থাকে, আৰু প্ৰতিটো `token` তাৰ হিব্ৰু শব্দৰ সৈতে বান্ধ খাই
থাকে।

**লিপি: অসমীয়া লিপি** — ৰ আৰু ৱ সহ। ভাষাৰ স্তৰ: প্ৰমিত লিখিত
অসমীয়া।

## হিব্ৰু — আটাইতকৈ আগত

এই অনুবাদ আপোনাক হিব্ৰুলৈ লৈ যাবৰ বাবে আছে — হিব্ৰুৰ ঠাই ল'বৰ
বাবে নহয়। বাৰে বাৰে পঢ়া হয় হিব্ৰু: তাৰ আখৰ, তাৰ ধ্বনি, তাৰ
চিহ্ন। অসমীয়া পাঠ এখন খিৰিকী, প্ৰতিস্থাপন নহয়। য'ত দুয়ো পৃথক
হয়, সত্য হিব্ৰুত।

## ফাইলৰ গঠন

```
<পুথি>/<অধ্যায়>/<পদ>.json
```

ফোল্ডাৰত পুথিৰ নাম ইংৰাজীত লিখা: `genesis/1/1.json`,
`psalms/33/12.json`।

প্ৰতিটো ফাইল:

```json
{
  "translation": "গোটেই পদটো যেনেকৈ পঢ়া হয়",
  "tokens": [{"surface": "হিব্ৰু শব্দ", "gloss": "অসমীয়া অৰ্থ"}]
}
```

`surface` — **পৃষ্ঠ**, হিব্ৰুৰ অভিলেখ। ই আমি লিখিবলগীয়া নহয়; ই
উৎসৰ পৰা আহে, আৰু সলনি নহয়।

`gloss` — **গ্লছ**, সেই এটা হিব্ৰু `token`-ৰ অসমীয়া অৰ্থ। গ্লছৰ
সংখ্যা হিব্ৰু শব্দৰ সংখ্যাৰ সমান। সদায়।

`translation` — **অনুবাদ**, এটা পদ নিজৰ ঠাইত, অসমীয়াত স্বাভাৱিকভাৱে
পঢ়িব পৰাকৈ।

`marks` — কেৱল ⟨את⟩ চিহ্নৰ `token`-ত: চিহ্নটোৱে দেখুওৱা অসমীয়া
শব্দ।

## ⟨ ⟩ কোণীয়া বন্ধনীৰ অৰ্থ

কোণীয়া বন্ধনী দুটা বেলেগ কামত লাগে, আৰু দুটাক পৃথক কৰাটো জৰুৰী।

**১ · ⟨את⟩ — অনূদিত নোহোৱা হিব্ৰু চিহ্ন।** হিব্ৰুত אֵת এটা সৰু
শব্দ, যি ক্ৰিয়াৰ কৰ্মৰ আগত থিয় হয়। অসমীয়াত ইয়াৰ সমতুল্য শব্দ
নাই, আৰু বহুতো অনুবাদে ইয়াক মনে মনে এৰি দিয়ে। আমি ইয়াক যেনেকৈ
লিখা আছে তেনেকৈ ৰাখোঁ — ই হিব্ৰুৰ গঠনৰ অংশ। ই ছপাৰ ভুল নহয়;
ই পাঠত থকা এটা শব্দ। চিহ্নটোৰ এটা পৰিয়াল আছে: את কেতিয়াবা
প্ৰত্যয় লৈ আহে (ואת, אתו, אתם) — সকলো একে পৰিয়ালৰ।

**২ · ⟨শব্দ⟩ — হিব্ৰুত নথকা অসমীয়া শব্দ।** সম্পূৰ্ণ অসমীয়া বাক্য
থিয় হ'বলৈ হিব্ৰুত নথকা এটা শব্দ লাগিলে, সেই শব্দটো বন্ধনীৰ
ভিতৰত ৰখা হয়। বন্ধনীয়ে কয়: *এই শব্দটো অনুবাদকে যোগ কৰিছে; ই
হিব্ৰুত নাই।*

**বন্ধনীৰ ভিতৰত বিদেশী ভাষা নাই।** তাত অসমীয়া থাকে, নহ'লে ⟨את⟩
চিহ্ন থাকে — তৃতীয় কিবা নাথাকে।

## নাম

নাম **অনুবাদ কৰা নহয়, উচ্চাৰণ অনুসৰি লিখা হয়**।

| হিব্ৰু | ইয়াত | প্ৰত্যাখ্যাত |
|---|---|---|
| יהוה | **ইয়াহৱেহ** | **যিহোৱা**, **প্ৰভু**, **সদাপ্ৰভু**, **ঈশ্বৰ** / **পৰমেশ্বৰ** নামৰ আসনত, **ভগৱান** |
| אלהים | **এলোহিম** | **ঈশ্বৰ** / **পৰমেশ্বৰ** নামৰ আসনত |
| אל | **এল** | ঈশ্বৰ / দেৱতা জাতিবাচক শব্দ হিচাপে নামৰ আসনত |
| אלוה | **এলোৱাহ** | — |
| אדני | **আদোনাই** | **প্ৰভু**, **প্ৰভু যিহোৱা** |
| שדי | **শ্বাদ্দাই** | **সৰ্বশক্তিমান** অকলে |
| יה | **ইয়াহ** | — |
| צבאות | **চেভাওত** | "বাহিনীসকলৰ" |
| שאול | **শ্বেওল** | "নৰক", "পাতাল" |

**যিহোৱা আৰু প্ৰভু অসমীয়া বাইবেলত বহু দিনৰ পৰা থিয় হৈ আছে।**
তথাপি ইয়াত সেইবোৰ নাই। প্ৰভু হৈছে এটা *উপাধিৰ* অনুবাদ, নামৰ
নহয়; যিহোৱা এটা সংকৰ ৰূপ। পাঠে יהוה কোৱা ঠাইত দুয়োটাই নামটো
ঢাকি দিয়ে। ইয়াৰ অৰ্থ এইটো নহয় যে সেইবোৰ বেয়া অসমীয়া — ইয়াৰ
অৰ্থ হ'ল সেইবোৰ **নামৰ ঠাইত** থিয় হয়। পৰম্পৰা শুনিব খোজা জনে
অন্য অসমীয়া বাইবেলত তাক পাব। ইয়াত যি লিখা আছে সেয়াই থিয় হয়।

*ইয়াহৱেহৰ চাৰিওটা আখৰ:* অসমীয়া লিপিয়ে יהוה-ৰ চাৰিওটা আখৰ বহন
কৰিব পাৰে — **ইয়া** (י) **হ** (ה) **ৱে** (ו) **হ** (ה)। শেষৰ ה কেৱল
ধ্বনি নহয়, নামৰ আখৰ; সেয়ে শেষৰ **হ** থাকে। ו-ৰ বাবে অসমীয়াৰ
নিজৰ আখৰ **ৱ**। এই আসনত নামটোৱেই অসমীয়াৰ চিন বহন কৰে।

**বিভক্তি ব্যাকৰণ।** ইয়াহৱেহে, ইয়াহৱেহক, ইয়াহৱেহৰ, ইয়াহৱেহত,
ইয়াহৱেহলৈ — এইবোৰ অসমীয়া ব্যাকৰণ, নামৰ সলনি নহয়; মূলটো অখণ্ড
থাকে। যিটো নিষিদ্ধ: মূল ভঙা (*ইয়াৱে*) বা মূলৰ আখৰ সলনি কৰা
(*যিহোৱা*, শেষৰ হ অবিহনে *ইয়াহৱে*)।

## সাধাৰণ *ঈশ্বৰ* আৰু *প্ৰভু*ৰ বৈধ আসন আছে

হিব্ৰুৱে জাতিবোৰৰ দেৱতা বা মানুহৰূপী প্ৰভুৰ কথা ক'লে, *দেৱতা*,
*দেৱতাবিলাক*, *প্ৰভু*, *মালিক* বৈধভাৱে থিয় হয় — এইটো নামৰ লোপ
নহয়, অনুবাদ। **হিব্ৰু `token`-এ সিদ্ধান্ত লয়, অসমীয়া শব্দটোৱে
নহয়।**

## চিহ্নিত শব্দ

- **হেচেদ** (חֶסֶד) — চুক্তিৰ অশেষ প্ৰেম। কেৱল "অনুগ্ৰহ" নহয়,
  কেৱল "দয়া" নহয়। এটা অসমীয়া শব্দে ইয়াক বহন নকৰে।
- **শ্বেওল** (שְׁאוֹל) — মৃতসকলৰ ঠাই, যেনেকৈ হিব্ৰুৱে কয়। নৰক নহয়।
- **মাশ্বিয়াহ** (מָשִׁיחַ) — **অভিষিক্ত জন** — তানাখৰ স্তৰত কেতিয়াও
  "খ্ৰীষ্ট" নহয়, "মচীহ"ও নহয়।
- **তোৰা** (תּוֹרָה) — শিক্ষা, নিৰ্দেশনা। **ברית** → **চুক্তি**।
- **শ্বাব্বাত** (שַׁבָּת) — জিৰণিৰ দিন, হিব্ৰুৰ নিজৰ শব্দেৰে।
- **নেফেশ্ব**, **ৰুৱাখ**, **কাভোদ** (נפש, רוח, כבוד) — প্ৰসংগ
  অনুসৰি (প্ৰাণ বা জীৱ; আত্মা, বতাহ বা উশাহ; মহিমা বা গধুৰতা) —
  এটা শব্দৰে বন্ধা নহয়।

ব্যক্তি আৰু ঠাইৰ নাম হিব্ৰুৰ ৰূপত: **আভ্ৰাহাম**, **ইৎচহাক**,
**য়াকোভ**, **মোশ্বে**, **আহৰোন**, **মিৎচৰায়িম**, **পাৰ'অ**,
**য়েহোশ্বুৱা**, **শ্বাউল**, **দাৱিদ**, **শ্বেলোমো**,
**য়েৰুশ্বালায়িম**।

## পদ তাৰ নিজৰ পোহৰত

প্ৰতিটো পদে নিজৰ ঠাইত যি কয় তাকেই কয় — এলোহিম এক বুলি কোৱা
হিব্ৰুৰ বিশ্বাসেৰে (দ্বিতীয় বিবৰণ ৬:৪) আমি ইয়াক পঢ়োঁ। পিছত অহা
মতবাদ পিছলৈ টনা নহয়; কাহিনীৰ শেষটো তাৰ আৰম্ভণিতে পঢ়া নহয়।
অনুবাদকে যি লিখা আছে তাকে দিয়ে — যোগ নকৰাকৈ, বাদ নিদিয়াকৈ।
